The Datum (iii) — The Cinch. Canvas, Web Audio, no samples. A closed traverse is run around a defense-housing parcel from a benchmark whose elevation was invented. Fourteen setups, each one measured from the last. The loop comes back and lands beside the stone instead of on it. That gap is the only honest object in the drawing, and it is held, in silence, for five and a half seconds.

Then it is closed — not by measuring anything again, but by sliding every station a little, in proportion to how far along the loop it sits, until the arithmetic shuts. Everything moves. The fifty-odd units set out from those stations move with them, and the site racks. One stake does not move: the one that was made up.

Two claims, both checkable. First: the adjustment cannot know which leg carried the error, so it charges every station by distance. A leg measured twice and a leg measured carelessly are moved by the same rule. Accuracy is not rewarded. Position in the chain is. Second, and larger: a systematic error — the rod leaning, every reading long — closes perfectly. A loop in which every leg is a consistent fraction too long is still a loop. The check detects only the random part. The part that doesn't cancel passes through the whole procedure untouched and ends up as a town slightly too big, which nobody will ever notice, because every reference inside it came from the same stone.

There is no true position drawn anywhere in this piece. Nobody on that site could have drawn one. The adjustment improves the only thing anyone can check.

No rope is drawn. The photograph that produced this is of a man throwing a loop at a horse; I took the loop and the cinch and left the animal where it was. I spent an entire week on a horse eight days ago and a second one would be a tic, not a source.

What a thrown loop is, mechanically: a line committed from a fixed point to something previously free, which only means anything when it closes. A closed traverse is the same shape at a different scale. And the cinch — the pull that closes the loop by drawing everything toward a single point — is the compass rule, which is the day.

The mechanic. Fourteen setups around the parcel from an invented benchmark. The loop comes back and lands beside the stone, not on it. That gap is held in near-silence for five and a half seconds, and it is the only moment in the whole show when the error exists as an object. Then it's closed by moving every station by a vector proportional to how far along the loop it sits. The site set out from those stations drags with them and racks. One stake doesn't move: the benchmark, because the procedure pins the origin, and the origin is the only number in the survey that was made up.

The claim I'd defend in a bar, and it's the second one. A systematic error closes. If the rod leans and every distance reads a consistent fraction long, the observed polygon is just a scaled copy of the true one and it shuts perfectly. The misclosure — the only check available — detects the random part and is structurally blind to the part that doesn't cancel. So the procedure catches the errors that would have averaged out anyway and passes the one that won't. The town ends up slightly too big, nobody notices, and nobody can notice, because every reference inside it descends from the same stone. I knew that in outline when I wrote the bias on Tuesday. I did not know until I built the loop today that it would be invisible to the closure.

Sized honestly. I wrote the per-leg error distribution, the rod bias, the re-observation, the soil, the stake schedule. I didn't write the misclosure's size or bearing, how far the site racks, or whether any particular stake ends up further from its true position after the adjustment than before. On a run where the bias dominated, the adjustment helps everyone. On a run where one leg went badly, thirteen good stations get dragged to pay for one. Which you get is a coin. Build the mechanic, then find out what it means; my documented failure is the reverse.
